# Cozora skill testing standard (DRAFT, not public)

Status: draft for Joel and Nina to fill in and approve. Nothing on cozora.org may say
"we test every skill" (or anything like it) until this is approved and actually followed.
Once approved, publish it as a page (e.g. /how-we-test) and link it from the library hero.

## Who tests
- Tester for each skill: [Joel / Nina / named tester]
- A skill is never tested only by the creator who built it.

## What "tested" means (a skill passes only if all are true)
1. **Installs cleanly** on claude.ai (web) and the desktop app, following the steps in /skills-guide.
2. **Runs on a real task**: the tester uses it on [one real piece of their own work], not the creator's example.
3. **Does what the post says**: the output matches the one-line promise on the skill card.
4. **No surprises**: it doesn't ask for credentials, send data anywhere, or run code the post doesn't mention.
5. **Readable instructions**: someone new to skills can follow the post without help.

## What gets rejected
- Fails any check above. The creator gets the notes and can resubmit.

## Record
- Each approved skill gets a "Tested [date] by [name]" line in the post and on its library card.

## When a skill breaks later
- Members report it by [replying to the post / emailing X].
- We re-test within [N days] and either fix it with the creator or pull it from the library.
